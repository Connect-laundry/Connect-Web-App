Frontend API Integration Guide: Auth & Registration
This document provides the necessary details for integrating the SIMAME backend authentication system into the laundry owner web app.

Base URL: https://connect-full-backend.onrender.com/api/v1/ Auth Pattern: JWT (JSON Web Token) via Bearer Header.

1. Authentication Overview
   All authenticated requests must include the following header: Authorization: Bearer <accessToken>

2. Endpoints Reference
   🔐 Login
   URL: POST /auth/login/
   Payload:
   json
   {
   "email": "owner@example.com",
   "password": "yourpassword"
   }
   Success Response (200 OK):
   json
   {
   "accessToken": "eyJhbG...",
   "refreshToken": "eyJhbG...",
   "user": {
   "id": "uuid",
   "email": "owner@example.com",
   "fullName": "John Doe",
   "role": "OWNER"
   }
   }
   📝 Registration
   URL: POST /auth/register/
   Payload:
   json
   {
   "email": "newowner@example.com",
   "phone": "+23354XXXXXXX",
   "first_name": "John",
   "last_name": "Doe",
   "role": "OWNER",
   "password": "StrongPassword123!",
   "password_confirm": "StrongPassword123!"
   }
   Success Response (201 Created):
   Performs auto-login and returns the same structure as the Login endpoint.
   🔄 Token Refresh
   URL: POST /auth/token/refresh/
   Description: Use this when the accessToken expires to get a new one using the refreshToken.
   Payload:
   json
   {
   "refresh": "your_refresh_token_here"
   }
   Success Response (200 OK):
   json
   {
   "accessToken": "new_access_token"
   }
   🚪 Logout
   URL: POST /auth/logout/
   Header: Authorization: Bearer <accessToken>
   Payload:
   json
   {
   "refreshToken": "token_to_blacklist"
   }
   👤 User Profile (Current)
   URL: GET /auth/me/ | PATCH /auth/me/
   Header: Authorization: Bearer <accessToken>
   Description: Get or update the currently logged-in user's profile details.
   🔑 Password Reset
   Request Reset Link: POST /auth/forgot-password/
   Payload: {"email": "user@example.com"}
   Result: User receives email with a link like ${FRONTEND_URL}/reset-password?token=<raw_token>
   Confirm Reset: POST /auth/reset-password/
   Payload: {"token": "token_from_url", "new_password": "new_secure_password"}
   🛠 Integration Best Practices
   Token Storage: Store refreshToken securely (e.g., in an HttpOnly cookie or secure storage) and accessToken in memory or session storage.
   Axios Interceptors: Implement an Axios interceptor to automatically attach the accessToken to outgoing requests and handle 401 Unauthorized by attempting a token refresh.
   Validation Errors: The backend returns structured errors for 400 Bad Request:
   json
   {
   "status": "error",
   "message": "Validation failed.",
   "data": {
   "email": ["This field must be unique."],
   "password": ["The password is too similar to the email."]
   }
   }
   Role Check: Ensure only users with role: "OWNER" are permitted to access the owner dashboard components.
